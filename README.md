# Proxim

Autonomous job-hunting agent — finds, scores, personalises, and applies to jobs with human-in-the-loop approval gates.

## Stack

- **Backend:** Python / FastAPI / LangGraph
- **Frontend:** TypeScript / Next.js
- **LLM:** Provider-configurable via LiteLLM (default: `claude-sonnet-4-6`)
- **Observability:** OpenTelemetry
