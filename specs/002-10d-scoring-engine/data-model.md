## Grade Computation (deterministic, in Python)

```
DIMENSION_WEIGHTS = {
    compensation: 3, company_stage: 3, interview_probability: 3,
    thought_leadership: 2, geography: 2, growth_trajectory: 2,
    domain_resonance: 2, hiring_urgency: 1
}
TOTAL_WEIGHT = 18

weighted_avg = sum(score * weight) / TOTAL_WEIGHT   # rounded to 1 decimal

gate_failed = (role_level_match.score < 2.5) OR (ai_stack_alignment.score < 2.5)

grade:
  gate_failed → F
  weighted_avg >= 4.5 → A
  weighted_avg >= 4.0 → B
  weighted_avg >= 3.0 → C
  weighted_avg >= 2.0 → D
  else              → F
```

Gate-pass dimension scores ARE stored in `score_10d.gate` but DO NOT contribute to `numeric_score` (FR-009).
