# Implementation Plan: Resume Tailoring Visibility & Outreach Insights

**Branch**: `proxim-mvp` | **Date**: 2026-05-26 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `/specs/009-resume-tailoring-insights/spec.md`

## Summary

Surface existing resume tailoring metadata (keywords, archetype, confidence, stale state) in the job card UI via a new `TailoredResumeCard` component, and add an `InsightsFunnelCard` to the dashboard showing outreach funnel counts, rate metrics, and archetype breakdown — all backed by a new `GET /api/candidates/[id]/insights` aggregation endpoint. No Python agent changes. No schema migrations.

## Technical Context

**Language/Version**: TypeScript 5.x, Next.js 15 (App Router)  
**Primary Dependencies**: Drizzle ORM (dual SQLite/Neon), shadcn/ui, Tailwind CSS v4, lucide-react, Vitest + Testing Library  
**Storage**: Neon PostgreSQL (prod) / SQLite (dev) — existing tables `resume_versions`, `jobs`, `email_cadences`, `email_drafts`  
**Testing**: Vitest + @testing-library/react (jsdom), `npm run test:run`  
**Target Platform**: Next.js web app, desktop-first  
**Project Type**: Web application (Next.js fullstack)  
**Performance Goals**: InsightsFunnelCard loads in < 2s (parallel fetch in Promise.all); TailoredResumeCard visible < 3s post-generation  
**Constraints**: No Python agent changes; no schema migrations; dual-runtime DB compatibility (SQLite dev + Neon prod)  
**Scale/Scope**: Per-candidate queries with candidateId indexes; up to 5 archetype rows in breakdown
